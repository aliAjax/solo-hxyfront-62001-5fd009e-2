# hxyfront-62001 船舶轮机值班记录

面向船舶轮机值班的前端记录系统，覆盖「开班 → 六类巡检录入 → 越限自动生成异常 → 异常流转闭环 → 交接班结转 → 历史检索」的完整值班闭环。数据保存在浏览器本地（localStorage），刷新不丢，后续可扩展为船队统一管理。

原始需求：轮机员记录主机转速、滑油压力、冷却水温、燃油消耗、舱底水状态和异常巡检项；支持值班班次切换、机舱参数看板、异常记录时间线、交接班摘要和按设备筛选的历史记录。

## 功能

- **班次管理**：开设班次（名称/轮机员必填，重复班次、当班未交接再开班均拦截）；交接后旧班次只读。
- **六类巡检录入**：主机转速、滑油压力、冷却水温、燃油消耗（数值型，含正常区间与硬量程双重阈值）、舱底水状态（正常/接近警戒/达到警戒）、异常巡检项（人工登记）。
  - 读数超正常区间但在量程内 → 自动关联设备生成异常单；超出量程、空提交一律拦截。
- **异常闭环**：待处理 → 处理中 → 已闭环（处理中可退回待处理；已闭环为终态）。越级/重复/终态流转拦截；开始处理需填措施，**闭环必须填写处置说明**；完整流转日志可查。
- **交接班**：按设备汇总本班巡检与未闭环异常；交接需新班次、接班轮机员、交接备注，二次确认后执行；旧班次转只读，未闭环异常连同原始记录（保留原发现班次）结转新班次继续跟进。
- **历史记录**：按班次、设备、异常状态（含"仅越限"）、关键字组合筛选，筛选条件与数据均持久化；导出 CSV（巡检记录 + 异常台账两段）；清空前需二次确认。
- **旧入口保留**：机舱参数看板（六类最新读数卡，越限标红）、异常记录时间线、设备筛选、交接摘要均在五个标签页内。

## 技术栈

React 19 + Vite 7 + TypeScript（无额外运行时依赖，纯本地存储）

## 本地运行

```bash
npm install
npm run dev      # 开发，端口 62001
npm run build    # 生产构建
npm run verify   # 类型检查 + 74 项纯逻辑验证 + 36 项 DOM 冒烟 + 构建
```

检查脚本兼容 Node 20 与 Node 22（Node 22 的 `navigator`/`localStorage` 为只读 getter 全局，注入 jsdom 对象时使用 defineProperty 回退，两版表现一致）。

## 代码结构

- `src/types.ts`：领域模型与异常状态机（合法流转表）
- `src/constants.ts`：六类巡检定义、设备清单、阈值
- `src/store.ts`：纯逻辑（开班/录入/流转/交接/持久化），不接触浏览器 API，可独立测试
- `src/selectors.ts`：历史筛选
- `src/export.ts`：CSV 导出与按设备交接摘要
- `src/App.tsx`：值班看板 / 巡检录入 / 异常处理 / 交接班 / 历史记录五个面板
- `scripts/verify.ts`、`scripts/dom-smoke.tsx`：验证脚本
